Win Agent

Win Agent is a personal, single-user tool that runs only on the owner's own computer. It helps the owner sort and summarize their own Gmail inbox. It is not offered to the public and has no other users.

Privacy Policy

Last updated: 2026-11-26

What the app accesses

With the owner's consent, Win Agent requests one Google permission: gmail.readonly (view email messages and settings). It cannot send, modify, move or delete email.

How data is used and stored

  • Email data is processed locally on the owner's computer to classify messages and produce a daily summary.
  • The authorization token is stored in the owner's operating-system keychain. Email bodies are not stored; only limited metadata and classification results are kept locally for a limited period.
  • Win Agent does not sell, share, or transfer Google user data to anyone, and does not use it for advertising.
  • An optional AI summary feature is off by default. If the owner turns it on, selected message text is sent to the AI provider the owner chooses, after local redaction, solely to produce that summary for the owner.

Limited Use

Win Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete local data on their own computer.
